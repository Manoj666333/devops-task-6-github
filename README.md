
# DevOps Internship Task 6: GitHub Pages

## Objective
Deploy a static website using GitHub Pages.

## Technologies Used
- HTML
- CSS
- GitHub
- GitHub Pages

## Implementation
1. Created an `index.html` file containing the website structure.
2. Used CSS to style the website.
3. Committed the source code to a GitHub repository.
4. Configured GitHub Pages to deploy from the `main` branch and root folder.
5. Verified the live website in a browser.

## Outcome
Successfully deployed a static website using GitHub Pages for free.
